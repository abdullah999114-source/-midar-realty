# MIDAR CONTROL CENTER

هذه النسخة تحول موقع مدار من ملفات HTML يدوية إلى نظام إدارة عقاري.

## ما الذي تحتويه؟
- موقع عام احترافي Responsive.
- تصنيفات: أراضٍ، فلل، شاليهات، استثماري، تجاري.
- لوحة تحكم على `/admin/`.
- إضافة/تعديل/أرشفة العقارات.
- رفع صور العقار إلى Supabase Storage.
- مرجع تلقائي يبدأ من `MIDAR-1003`.
- إدارة العملاء والاستفسارات.
- حالات: منشور / مسودة / مؤرشف.
- عرض مميز Featured.
- بيانات MIDAR-1001 و MIDAR-1002 كبداية.
- ربط مباشر بواتساب ورابط الخريطة.
- Netlify config جاهز.

## الإعداد مرة واحدة
1. أنشئ/استخدم مشروع Supabase.
2. افتح SQL Editor ونفذ الملف `sql/setup.sql`.
3. من Project Settings > API انسخ Project URL و anon public key.
4. ضع القيم في `assets/config.js`.
5. من Supabase Auth > Users أنشئ مستخدم الإدارة (بريد + كلمة مرور).
6. ارفع المشروع كاملًا إلى GitHub في مستودع `midar-realty`.
7. Netlify سينشر تلقائيًا من GitHub.

بعد ذلك لن تحتاج تعديل GitHub لإضافة عقار؛ استخدم `/admin/` فقط.
